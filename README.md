# EG AI 助手（Edge 扩展）

用一句话检索网站/视频/图片、自动识别并翻译英文、总结网页要点、解析下载抖音与 B站分享链接。AI 接入云端 OpenAI 兼容接口。

## 安装

1. Edge 打开 `edge://extensions/`
2. 开启「开发人员模式」
3. 「加载解压缩的扩展」→ 选择本文件夹

## 配置

侧边栏右上角 ⚙ 填 API Base / API Key / 模型名（如 DeepSeek：`https://api.deepseek.com/v1` + `deepseek-chat`），点「测试模型」。

不填 Key 也能用：百度/必应检索 + 必应翻译 + 本地摘要。

## 用法

- 检索：`找几个学 Rust 的中文教程网站`
- 找视频：`量子力学 入门 视频讲解`
- 找图片：`找几张量子力学示意图`（网格展示，图右下角可保存）
- 翻译：粘贴英文段落 / 选中文字右键 / 点「译页」
- 总结：打开侧边栏自动总结，或点「要点」
- 下载：粘贴 `https://v.douyin.com/...` 或 `https://www.bilibili.com/video/BV...`
